ISMS TYPING RACE - OFFLINE / DESKTOP

QUICKEST (no install):
  Double-click index.html. It opens in Chrome or Edge and works with no internet.
  Your scores are saved in that browser.

AS A REAL DESKTOP APP (needs Node.js once, internet only for the first install):
  1. Open a terminal in this folder.
  2. npm install
  3. npm start              -> opens the app in its own window
  4. npm run build          -> makes a portable .exe in the dist folder (Windows)
After that, the app runs with no internet.

Note: offline, the typewriter font falls back to Courier New.
Keep the slides folder next to index.html, or the Source slides view will be blank.
UPDATING: replace index.html and the slides folder, then run npm run build again.
